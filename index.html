02 / CAPABILITY MAP

跨越分工，不丢失细节。

我希望承担的不只是单一模块开发，也包括把策划意图、美术资源与实际游戏反馈连接起来的工作。

01

玩法与系统设计

拆解战斗、成长、经营与卡牌规则，明确触发条件、状态转移、数值边界和玩家反馈，再为实现定义可检验标准。

  • 战斗机制
  • 数值模型
  • 资源结算
  • GDD
02

程序与工具实现

从 C# / Lua 的运行时机制到 Godot、Unity、UE 的客户端开发，重视数据驱动、模块边界、日志和自动验证。

  • C# / Lua
  • Godot
  • Unity / UE
  • Python
03

视觉资产与落地

把美术需求转为可用资产规格：AI 生成概念与界面参考、切分和整理图像、调整导入格式并在引擎里验证最终效果。

  • AI 视觉辅助
  • 2D 资产处理
  • UI 实现
  • 引擎整合
03 / HOW I WORK

一个循环，
从想法到验证。

好的设计需要被实现，好的实现需要被玩家感知。我倾向于把文档、代码、素材和测试放在同一条可追踪的迭代链条中。

  1. 01
    定义体验目标玩家应该如何判断、行动、得到反馈。
  2. 02
    把规则转为契约条件、时序、边界、数据与失败路径。
  3. 03
    构建可玩切片代码、资产、UI 与声音共同形成可操作体验。
  4. 04
    测试并留下证据日志、场景测试、回归检查与真实试玩共同收敛设计。
